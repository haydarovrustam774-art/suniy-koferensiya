# Ilmiy Konferensiya Elektron Tizimi

Ushbu loyiha Google Workspace bulutli texnologiyalari va HTML integratsiyasi asosida yaratilgan avtomatlashtirilgan ro'yxatga olish tizimidir.

## 🚀 Loyiha arxitekturasi
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Google Apps Script (`Code.gs`)
- **Ma'lumotlar bazasi:** Google Sheets & Google Forms

## ⚙️ Ishlash jarayoni
1. Tizim ishga tushganda yo'nalishlar Google Sheets bazasidan avtomatik olinadi.
2. Qatnashchi ma'lumotlarni interfeys orqali kiritadi.
3. Barcha javoblar zudlik bilan Google Forms va Sheets bazasiga yoziladi.
